# 1.3 验证 GPU 链路：跑一个示例

> **对应 SLT**：我能运行一个 GPU 图像处理示例，验证 CUDA 设备与算子已正确启用。
> **课时类型**：How To Guide
> **前置**：1.1 编译好的 OpenCV CUDA、1.2 的 CMake 检测

---

## 为什么要有这一步

环境装好了，不代表用得上。常见的坑是：编译期找到了 CUDA，运行时却链接到 CPU 版库；或者能找到设备，算子却因缺模块而退化。**在写业务代码之前，先用一个最小程序把整条链路验一遍。**

目标很简单：能查到设备、能跑一个 `cv::cuda` 算子、能拿到可见的输出。

---

## 步骤 1：确认设备可见

最小检查，先不碰图像：

```cpp
#include <opencv2/core/cuda.hpp>
#include <iostream>

int main()
{
    int count = cv::cuda::getCudaEnabledDeviceCount();
    std::cout << "CUDA 设备数: " << count << "\n";
    if (count <= 0) {
        std::cerr << "没有可用 CUDA 设备，检查是否 source 了环境脚本\n";
        return 1;
    }
    cv::cuda::printShortCudaDeviceInfo(0);
    return 0;
}
```

`printShortCudaDeviceInfo` 会打印设备名、显存、算力。**必须看到这些输出**，不能静默退出。

Python 等价版：

```bash
source ~/opt/opencv-cuda/opencv_cuda_env.sh
python3 -c "import cv2; print('设备数:', cv2.cuda.getCudaEnabledDeviceCount())"
```

预期打印 `设备数: 1`。

---

## 步骤 2：跑一个 GPU 算子

用一张程序生成的纯色图，避免依赖外部图片文件。做一次 BGR→灰度 + 高斯模糊，都在 GPU 上：

```cpp
#include <opencv2/core.hpp>
#include <opencv2/core/cuda.hpp>
#include <opencv2/cudaimgproc.hpp>

#include <iostream>

int main()
{
    if (cv::cuda::getCudaEnabledDeviceCount() <= 0) {
        std::cerr << "没有可用 CUDA 设备\n";
        return 1;
    }
    cv::cuda::setDevice(0);
    cv::cuda::printShortCudaDeviceInfo(0);

    // 生成一张 1920x1080 的 BGR 图（纯色加一个亮块）
    cv::Mat host(1080, 1920, CV_8UC3, cv::Scalar(30, 60, 90));
    host(cv::Rect(800, 400, 200, 200)).setTo(cv::Scalar(200, 200, 200));

    cv::cuda::GpuMat g_src, g_gray, g_blur;
    g_src.upload(host);
    cv::cuda::cvtColor(g_src, g_gray, cv::COLOR_BGR2GRAY);
    cv::cuda::GaussianBlur(g_gray, g_blur, cv::Size(5, 5), 0);

    cv::Mat out;
    g_blur.download(out);

    std::cout << "输出尺寸: " << out.cols << "x" << out.rows
              << "  通道: " << out.channels() << "\n";
    std::cout << "输出均值: " << cv::mean(out)[0] << "\n";
    return 0;
}
```

`cvtColor` 与 `GaussianBlur` 来自 `<opencv2/cudaimgproc.hpp>`。

编译时用 1.2 里的 CMake 工程，或临时用 `pkg-config`：

```bash
source ~/opt/opencv-cuda/opencv_cuda_env.sh
g++ verify_cuda.cpp -o verify_cuda $(pkg-config --cflags --libs opencv4)
./verify_cuda
```

---

## 验证要点

运行后，输出里应同时出现：

1. **设备信息**：一行 GPU 名称与算力。
2. **输出尺寸**：`1920x1080  通道: 1`（灰度图是单通道）。
3. **输出均值**：一个 0–255 之间的数。纯色区域与亮块会把它拉到一个中间值。

**判断标准**：三项都打印出来，且尺寸与通道正确，说明 `cv::cuda` 已经真的在 GPU 上跑算子。

如果你想更严格，可以再做一次 CPU 对照：用 `cv::cvtColor`/`cv::GaussianBlur` 处理同一个 `host`，比较 GPU 与 CPU 的输出均值是否接近。

## 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `设备数: 0` | 没 `source` 环境脚本 | `source ~/opt/opencv-cuda/opencv_cuda_env.sh` |
| 运行时报找不到 `libopencv_*.so` | `LD_LIBRARY_PATH` 没指向独立前缀 | 重新 `source` |
| 编译报找不到 `cudaimgproc.hpp` | 链接的是 CPU 版 OpenCV | 确认 `pkg-config`/`OpenCV_DIR` 指向 CUDA 版 |
| 程序无输出直接结束 | `return` 分支被走到但没打印 | 检查 `getCudaEnabledDeviceCount` 的返回值 |
| 第一次运行很慢 | CUDA 上下文首次初始化 | 属正常，预热一两次再计时 |
